# Digital Business Card

This website is a retro inspired digital business card by Josh Daponte.

My design supports my intended audience by presenting my work and identity in a visually engaging way that reflects my style as a designer. The layout allows users to interact with my portfolio and contact links in a clear and visually interesting way. I added hover states that scale the buttons and swap images to create a peeling effect. The layout adapts on smaller screens using a media query, since the original composition would not work well in a vertical format. If I continued developing this page, I would update some of the links.
